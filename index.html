Banking SQL practice

Exercises cover reusable database logic rather than only simple selects: a CTE ranks balances, window functions preserve ties, and scalar/table-valued functions package common queries.

Read the SQL source → 
WITH ranked_accounts AS (
  SELECT account_id,
         balance,
         RANK() OVER (
           ORDER BY balance DESC
         ) AS balance_rank
  FROM account
)
SELECT *
FROM ranked_accounts
WHERE balance_rank <= 3;

Separate future repository

Egypt Weather Forecasting System

The current-weather ETL notebook is the seed, not the finished ML project. The next repository will collect historical observations, establish time-based baselines, train forecasting models without temporal leakage, expose inference through an API, and present forecasts in a dedicated frontend.

  1. 01
    Historical data pipelineScheduled, idempotent ingestion with schema and freshness checks.
  2. 02
    Forecast evaluationTime splits, seasonal baselines, MAE/RMSE, and city-level errors.
  3. 03
    ML serviceVersioned preprocessing, model registry, FastAPI inference, and tests.
  4. 04
    User experienceForecast dashboard, uncertainty, monitoring, Docker, and cloud deployment.
Repository boundary: forecasting code will live in its own repository. This DEPI repository documents the learning path and preserves the secure ingestion prototype.
