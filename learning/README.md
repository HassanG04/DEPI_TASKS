# Learning evidence

This directory contains curated artifacts selected from the local DEPI coursework. Files are included when they provide useful, inspectable evidence and can be published safely.

## Included

- `python/python_foundations.ipynb`: original introductory programming and object-oriented coursework.
- `advanced-python/weather_etl.ipynb`: a rewritten, secret-free form of the weather API exercise.
- `sql/banking_queries.sql`: SQL Server functions, CTEs, ranking, joins, and common transformations.
- `flask/flask_intro.ipynb`: the introductory Flask route/template exercise.

## Intentionally excluded

- SQL Server `.bak` files: binary classroom databases are not appropriate website assets.
- Credentials from classroom instructions or local notebooks.
- Generated screenshots and transient browser output.
- The incomplete Naukrigulf scraping notebook.
- A Wuzzuf prototype with brittle selectors and broad exception handling; the learning is documented without presenting that implementation as reliable.

The original local coursework remains under `D:\Projects\Programming\DEPI`. This repository contains only the public, curated evidence.
